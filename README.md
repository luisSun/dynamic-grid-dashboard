🧪 **Anime Harem Chart Creator**
A simple and fun tool to generate classic-style *anime harem charts*, allowing custom images, dynamic slots, theme switching, and PNG export.

---

## ✨ Features

* ➕ **Add new slots** dynamically
* 🖼️ **Upload custom images** from local files
* 🔍 **Image preview** before confirming
* 🗑️ **Remove images** individually
* 🌗 **Dark / Light mode** toggle
* ♻️ **Reset chart** (removes images and restores buttons)
* 💾 **Save as PNG** using html2canvas

---

## 🚀 Technologies Used

* **HTML5**
* **CSS3** (modular: style.css, style-modal.css, nav.css)
* **Vanilla JavaScript**
* **html2canvas** for PNG export

---

## 🧭 How to Use

1. Click **Add a Blank Space** to create new slots.
2. Click the **+** inside any slot to upload an image.
3. Select your file and preview it in the modal.
4. Confirm to insert the image.
5. Use **Save as PNG** to export your harem chart.
6. Toggle **Dark Mode** anytime.
7. Use **Reset Chart** to clear images.
